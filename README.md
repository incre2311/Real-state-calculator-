# Crest Capital – Real Estate Investment Analyzer

**A calmer way to read the numbers.**

Crest Capital is a complete real estate investment underwriting tool that helps you analyze deals, stress-test assumptions, compare properties, and understand what's actually driving the return.

---

## 🔗 Live Demo

Try the calculator before you buy:
**[https://incre2311.github.io/Real-state-calculator-/](https://incre2311.github.io/Real-state-calculator-/)**

---

## 🎯 What It Does

Enter property assumptions and get instant analysis:

| Metric | What It Tells You |
|--------|-------------------|
| **IRR** | Annualized return on investment |
| **Cap Rate** | Property yield based on NOI |
| **DSCR** | Debt Service Coverage Ratio |
| **Monthly Cash Flow** | How much you pocket each month |
| **Equity Multiple** | Total cash returned per dollar invested |
| **Investment Score** | 0–100 rating of deal quality |
| **Exit Equity** | Equity after selling the property |

---

## 📊 Key Features

- ✅ Full underwriting model (IRR, Cap Rate, DSCR, Cash Flow)
- ✅ Interactive charts (Property Value & Equity, Cash Flow & NOI)
- ✅ Scenario analysis (Conservative / Base / Optimistic)
- ✅ Sensitivity analysis
- ✅ Property comparison (A vs B)
- ✅ Investment tuner slider
- ✅ Natural language chatbot
- ✅ Save / Load / Manage deals
- ✅ Multi-currency support (INR, USD, EUR, GBP)
- ✅ Responsive design
